# Nested Tic-Tac-Toe · 井中井

[简体中文](README.md) · [日本語](README.ja.md) · English

Nested Tic-Tac-Toe is a Windows game based on a version of tic-tac-toe I made up and played with classmates in high school. Each of the nine squares on the main board holds a smaller game. You can share a PC with a friend or play against the computer.

## Download

Download the Windows x64 ZIP from the [latest release](https://github.com/Resuty/Nested-Tic-Tac-Toe/releases/latest). Extract the whole archive, then run `NestedTicTacToe.exe`.

Use the mouse to play. The game works offline. Against the computer, you can choose who goes first. Settings include volume, mute, and a language picker for Simplified Chinese, Japanese, and English.

## How to play

1. O goes first and can pick any empty cell. After that, the cell number tells the other player which board to use. Play in cell 8 and your opponent goes to board 8.
2. Get three in a row to win a small board. If it fills up with no winner, it ends in a draw. A finished board is closed. If you get sent to one, pick any board that's still open.
3. Win three small boards in a row, column, or diagonal to win the match. If all nine boards close and neither player has that line, the match is a draw.

## Open the Unity project

Open the repository root in **Unity 6000.6.0f1**, then open [WellWithinWell.unity](Assets/Scenes/WellWithinWell.unity) and press Play.

Use `Window → General → Test Runner` to run the Edit Mode and Play Mode tests. With Windows Build Support installed, use `井中井 → 构建 Windows 游戏` to build the player into `Build/Windows`.
